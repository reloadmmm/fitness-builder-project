# FitnessBuilderProject

Проект демонстрирует паттерн Builder для создания планов тренировок.

## Возможности
- Создание силового плана тренировок
- Создание кардио плана тренировок
- Директор (TrainingPlanDirector) управляет сборкой плана

## Как запустить
1. Открыть FitnessBuilderProject.sln в Visual Studio
2. Нажать F5

## Пример работы
Программа создает тренировочные планы через билдера и выводит результат в консоль.
